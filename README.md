# เว็บไซต์ครบรอบ 2 ปี — อิมชิ ♡ เบบิ่

เว็บไซต์ฉลองครบรอบ 2 ปี แบบ static ไม่ต้องติดตั้งอะไร เปิดไฟล์ `index.html` ได้เลย

## เปิดเว็บไซต์

- ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์
- หรือถ้าถนัดเปิดผ่าน local server: `npx.cmd serve .` แล้วเปิด URL ที่แสดง

## รูปและวิดีโอ

ตอนนี้หน้าเว็บใช้ไฟล์จริงแล้ว:

- รูปแรก (hero): `assets/roblox.png` (ภาพคู่ใน Roblox)
- รูปในส่วนโมเมนต์: `assets/photo.jpg` (แปลงจาก `assets/photo-original.heic` เป็น JPEG แล้ว)
- วิดีโอ Boomerang: `assets/boomerang.mp4` (แปลงจาก `assets/boomerang.mov` เป็น H.264 MP4 แล้ว)
- ภาพ poster ของวิดีโอ: `assets/video-poster.jpg`

ระบบจะโหลดรูปและวิดีโอขึ้นหน้าเว็บอัตโนมัติ โดยวิดีโอจะเล่นไปข้างหน้าแล้วย้อนกลับให้เป็น Boomerang และปิดเสียงไว้

ลิงก์ Google Drive ของต้นฉบับยังอยู่ในปุ่ม “เปิดรูปของเรา” และ “เปิดวิดีโอของเรา” หมายเหตุ: ลิงก์ Drive ที่ให้มาเป็นแบบต้องขอสิทธิ์เข้าถึง จึงไม่สามารถฝังในหน้าเว็บโดยตรงได้

ถ้าต้องการเปลี่ยนรูปหรือวิดีโอ ให้วางไฟล์ใหม่ทับชื่อเดิม:

- รูปหน้าแรก: `assets/roblox.png`
- รูปในโมเมนต์: `assets/photo.jpg`
- วิดีโอ: `assets/boomerang.mp4`

ถ้าไม่มีไฟล์ ระบบจะแสดงภาพประกอบสำรอง (`photo-placeholder.svg` และ `video-placeholder.svg`) แทน

## แก้ข้อความ

ข้อความทั้ง 9 ข้อความอยู่ใน `script.js` ตัวแปร `messages` แก้ข้อความในเครื่องหมายคำพูดได้เลย

## ไฟล์ในโปรเจกต์

- `index.html` — โครงสร้างหน้าเว็บ
- `style.css` — ธีมสีขาวอมครีม ชมพูอ่อน และการจัดวางแบบ responsive
- `script.js` — ข้อความ, ปุ่มเลื่อนข้อความ, วิดีโอ Boomerang, เครื่องเล่นเพลง และเอฟเฟกต์เล็ก ๆ
- `assets/` — รูป วิดีโอ ภาพประกอบ และปกเพลงใน `assets/music/` (`best-luck.jpg` คือปกเพลงที่ใช้อยู่)
